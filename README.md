# BINGO DRAW

新卒同期会などの会場で、司会者がビンゴ番号を抽選してモニターに表示するための静的 Web アプリです。
バーやダーツ会場でも使いやすいように、暗めの背景、赤/緑/ゴールドのアクセント、遠くから読める大きな番号表示にしています。
参加者管理、ログイン、オンライン同期、ビンゴカード配布機能はありません。

実装本体は `index.html` だけで完結しています。CSS と JavaScript も `index.html` 内に含まれているため、サーバーなしでそのまま開けます。

## 使い方

1. `index.html` をブラウザで開きます。
2. 必要に応じて「フルスクリーン」を押し、画面をモニターに投影します。
3. 「次の番号を引く」を押すと、短い抽選演出のあと番号が確定します。
4. 誤って進めた場合は「1つ戻す」で直近の番号を取り消せます。
5. 最初からやり直す場合は「リセット」を押します。確認ダイアログが表示されます。

抽選状態はブラウザの `localStorage` に自動保存されます。同じブラウザで開き直すと、抽選済み番号、現在番号、履歴が復元されます。

iPad ではファイルアプリから `index.html` を直接開くのではなく、GitHub Pages の公開 URL を Safari で開いてください。ファイルアプリ経由では JavaScript が正しく動かない場合があります。

## ローカルで開く方法

特別なセットアップは不要です。

```powershell
start .\index.html
```

または、エクスプローラーで `index.html` をダブルクリックしてください。

## GitHub Pagesで公開する方法

公開 URL:

```text
https://hayatanni.github.io/bingo-draw-app/
```

1. このフォルダーを GitHub リポジトリに push します。
2. GitHub のリポジトリ画面で `Settings` を開きます。
3. `Pages` を開きます。
4. `Build and deployment` の `Source` で `Deploy from a branch` を選びます。
5. 公開するブランチと `/root` を選び、保存します。
6. 表示された GitHub Pages の URL を開き、`index.html` が表示されることを確認します。

公開後は、iPad Safari で GitHub Pages の URL を開いて使用してください。

## 本番前チェックリスト

- [ ] 1〜75の番号が重複せずに出る
- [ ] B / I / N / G / O の表示が正しい
- [ ] 抽選演出が動く
- [ ] 抽選済み番号一覧が見やすい
- [ ] スマホ縦画面で崩れない
- [ ] PC横長画面で崩れない
- [ ] モニターに映して番号が読める
- [ ] 画面を閉じて開き直しても状態が復元される
- [ ] 1つ戻すが正常に動く
- [ ] リセット確認が出る
- [ ] 75個すべて引いた後に次の抽選ができない
- [ ] 本番前に通知オフ、画面ロック解除、充電確認をする

## トラブル時の対応

- 状態がおかしい場合: 「リセット」で抽選状態を初期化してください。
- 開き直しても復元されない場合: 別ブラウザやシークレットモードでは保存領域が別になります。本番で使うブラウザを固定してください。
- フルスクリーンにならない場合: ブラウザや端末が対応していない可能性があります。ブラウザの表示メニューや OS 側のミラーリング設定を使ってください。
- モニターで文字が小さい場合: ブラウザのズームを上げるか、PC の表示スケールを調整してください。
- スマホで画面が暗くなる場合: 本番前に自動ロックを解除し、充電しながら使ってください。

## メモ

- 番号範囲は標準的な 1〜75 のビンゴです。
- 表示は `B-7`、`I-23` のように列名付きです。
- 効果音は入れていません。追加する場合は `index.html` 内の確定処理コメント付近に再生処理を追加してください。
